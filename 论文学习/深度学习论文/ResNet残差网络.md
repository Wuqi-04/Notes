# ResNet：深度残差学习

> He, K., Zhang, X., Ren, S., & Sun, J. (2016). Deep Residual Learning for Image Recognition. CVPR 2016.
>
> arXiv: https://arxiv.org/abs/1512.03385

## 解决的问题

网络加深时出现**退化问题（degradation problem）**：深度增加后，准确率饱和然后急剧下降。这不是过拟合——训练误差也上升了，说明深层网络更难优化。

## 核心思想

与其让网络直接学习目标映射 H(x)，不如学习残差：

$$F(x) = H(x) - x$$

网络输出变为：

$$H(x) = F(x) + x$$

通过 shortcut connection（恒等映射）将输入直接加到输出。如果最优映射接近恒等映射，只需把 F(x) 推向0，比重新学习一个恒等映射容易得多。

## 为什么有效

1. **梯度直通**：反向传播时，梯度可以通过 shortcut 直接传回浅层，至少有 1.0 的梯度通路，缓解梯度消失（每次计算都会导致梯度降低，而增加了残差模块后，通过直连可以缓解该现象，防止梯度弥散）
2. **恒等映射容易学习**：残差为0比重新学习恒等映射简单
3. **不增加参数和计算量**：shortcut 是逐元素相加，无可学习参数

## 网络结构

- ResNet-18/34：基本残差块（两个3x3卷积）
- ResNet-50/101/152：瓶颈块（1x1 + 3x3 + 1x1），先降维再升维，减少计算量
