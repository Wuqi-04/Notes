# 深度学习框架

## 主流框架

目前主流的深度学习框架有两个：

- **PyTorch**：动态图优先，便于调试，适合学术研究
- **TensorFlow**：静态图优先，生态完善，适合工业部署

### 动态图 vs 静态图

核心差异：动态图优先 or 静态图优先。

**动态图（PyTorch）**：
- 先创建变量，再对变量进行运算，最后得到结果
- 运行时中间过程可以进行干预
- 在任意一个运行步骤都可以暂停，动态调参
- 便于调试，适合学术研究

**静态图（TensorFlow）**：
- 图的创建和图的运行进行了分离
- 先创建函数，再代入变量运算，最后得到结果
- 运行时中间过程无法进行干预
- 生态完善，适合工业部署

### PyTorch生态

- 自然语言处理：AllenNLP
- 视觉应用：TorchVision
- 图卷积：PyTorch Geometric、Fast.ai
- 训练好的模型可通过 ONNX 协议进行快速部署

## PyTorch的核心功能

### 1. GPU加速

- CPU直接运算：`torch.tensor([1, 2])`
- GPU运算：`.cuda()` 或 `.to('cuda')`，利用GPU并行计算
- 首次GPU运算需要配置环境，所以时间较长

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0])
x = x.cuda()       # 搬到GPU
# 或
x = x.to('cuda')
```

### 2. 自动求导

- 神经网络层数再深，本质上都是一系列函数的偏导
- `requires_grad=True` 表示对该张量求导（求梯度）
- PyTorch会自动构建计算图，通过反向传播计算梯度

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward()       # 反向传播
print(x.grad)      # tensor(4.)，即 dy/dx = 2x = 4
```

### 3. 常用网络层

PyTorch提供了常用的网络层（`torch.nn`），可以用简单的网络层构建复杂神经网络：

- `nn.Linear`：全连接层
- `nn.Conv2d`：二维卷积层
- `nn.ReLU`、`nn.Sigmoid`：激活函数
- `nn.MaxPool2d`：池化层
- `nn.CrossEntropyLoss`：交叉熵损失
- `nn.Sequential`：顺序容器
