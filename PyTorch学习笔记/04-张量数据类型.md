# 张量数据类型

## 数据类型

PyTorch内部没有string类型，字符串通过以下方式表示：
- One-hot编码
- Embedding（嵌入向量）

常用类型：
- `torch.float32` / `torch.float`：32位浮点（默认）
- `torch.float64` / `torch.double`：64位浮点
- `torch.int64` / `torch.long`：64位整型
- `torch.int32` / `torch.int`：32位整型
- `torch.uint8`：8位无符号整型
- `torch.bool`：布尔型

比较时常用 `torch.float32`。

## 类型推断

```python
a = torch.tensor([1.0, 2.0])

# 方式1
print(a.type())       # torch.FloatTensor

# 方式2
print(isinstance(a, torch.FloatTensor))  # True
```

注意：部署在CPU和GPU上的数据类型不同，GPU上为 `torch.cuda.FloatTensor`。

## 不同维度的张量

### Dimension 0（标量）

```python
a = torch.tensor(1.0)
```

- Loss通常是标量，用Dimension为0的tensor表示
- 判断方式：
  - `a.shape` → `torch.Size([])`
  - `a.size()` → `torch.Size([])`
  - `len(a.shape)` → 0
- `[]` 表示维度为0的张量

### Dimension 1（向量）

```python
# 方式1：直接初始化
a = torch.tensor([1.0, 2.0, 3.0])

# 方式2：指定维度，随机初始化
b = torch.FloatTensor(3)

# 方式3：从numpy导入
import numpy as np
data = np.ones(3)
c = torch.from_numpy(data)  # tensor([1., 1., 1.], dtype=torch.float64)
```

用途：
- Bias（偏置值）
- Linear Input（全连接层输入）

### Dimension 2（矩阵）

```python
a = torch.randn(3, 4)       # 随机正态分布
b = torch.FloatTensor(3, 4) # 指定维度
```

- `a.size(0)` 返回第0维长度
- `a.size(1)` 返回第1维长度

### Dimension 3

```python
a = torch.rand(10, 20, 100)
```

- 随机均匀分布，从[0,1]生成
- 适合RNN输入：[10, 20, 100] 表示10个单词、20个句子、每个单词100维嵌入
- 可理解为操作系统的多级索引表
- `a[0]` 表示 tensor[20, 100]

### Dimension 4

```python
a = torch.rand(4, 3, 224, 224)
```

适合CNN输入：[b, c, h, w]
- b：batch，一次处理多少张图片
- c：channel，通道数（灰度图为1，RGB为3）
- h：height，图片高度
- w：width，图片宽度

## 概念区分

- **Dimension**：size/shape的长度（维度数）
- **Size/Shape**：每一维有几个元素（可理解为索引）
- **Tensor**：具体数据本身

## 常用方法

```python
a = torch.rand(4, 3, 28, 28)
a.numel()    # 张量元素总数：4*3*28*28 = 9408
a.dim()      # 维度数：4
list(a.shape)  # 转为Python list：[4, 3, 28, 28]
```
