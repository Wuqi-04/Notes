# 池化与上采样

## 池化层

池化层用于空间压缩和特征筛选，没有可学习的权重。

### 最大池化（Max Pooling）

取窗口内最大值：

```python
nn.MaxPool2d(kernel_size=2, stride=2)
```

- 保留最显著的特征
- 最常用

### 平均池化（Average Pooling）

取窗口内平均值：

```python
nn.AvgPool2d(kernel_size=2, stride=2)
```

- 保留整体信息
- 全局平均池化（GAP）常用于替代全连接层

### 池化的作用

1. 降低特征图空间尺寸，减少计算量
2. 扩大感受野
3. 提供一定的平移不变性
4. 特征选择（Max Pooling选择最显著特征）

## Batch Normalization（批归一化）

将输入的值做等效转换，使其范围落在有效区间内：

$$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$$
$$y = \gamma \hat{x} + \beta$$

```python
nn.BatchNorm2d(num_features=64)
```

作用：
- 加速训练收敛
- 允许使用更大学习率
- 有轻微正则化效果
- 训练时用batch统计量，测试时用移动平均统计量

## 上采样

上采样是池化的逆操作，增大特征图空间尺寸。

### 简单上采样

```python
nn.Upsample(scale_factor=2, mode='nearest')  # 最近邻复制
nn.Upsample(scale_factor=2, mode='bilinear') # 双线性插值
```

- 最近邻：直接复制像素，简单但有锯齿
- 双线性：插值平滑，更自然

### 转置卷积（Transposed Convolution）

```python
nn.ConvTranspose2d(in_channels, out_channels, kernel_size=3, stride=2, padding=1, output_padding=1)
```

- 有可学习权重
- 常用于语义分割、超分辨率等需要恢复空间分辨率的任务
- 注意：转置卷积容易产生棋盘效应（checkerboard artifacts）
