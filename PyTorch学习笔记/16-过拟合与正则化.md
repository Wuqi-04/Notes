# 过拟合与正则化

## 过拟合与欠拟合

### 欠拟合（Underfitting）
- 模型在训练集上表现就很差
- 原因：模型容量不足、特征不够、训练不充分
- 解决：增加模型复杂度、增加特征、训练更久

### 过拟合（Overfitting）
- 训练集表现很好，但测试集/验证集表现差
- 模型"死记硬背"训练数据，泛化能力差
- 训练loss持续下降，但测试loss先降后升

### 解决过拟合的方法
1. 更多数据
2. 正则化（L1/L2）
3. Dropout
4. Early Stopping
5. 数据增强
6. 降低模型复杂度

## 交叉验证（Cross Validation）

### K折交叉验证

将训练数据分成K份，每次用K-1份训练、1份验证，循环K次，取平均性能。

```python
from sklearn.model_selection import KFold

kf = KFold(n_splits=5, shuffle=True)
for train_idx, val_idx in kf.split(X):
    X_train, X_val = X[train_idx], X[val_idx]
    # 训练并验证
```

- 优点：更充分利用数据，评估更稳定
- 缺点：训练K次，计算成本高
- 实际使用中提升不高，使用不多

## 正则化（Regularization）

### L2正则化（权重衰减）

$$L_{total} = L_{data} + \lambda \sum w^2$$

- 在损失函数中加入权重的平方和
- 限制权重过大，使模型更平滑
- $\lambda$ 控制正则化强度

```python
# PyTorch中通过weight_decay参数实现
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4, weight_decay=1e-4)
```

### L1正则化

$$L_{total} = L_{data} + \lambda \sum |w|$$

- 产生稀疏权重（部分权重为0）
- 可用于特征选择

## Early Stopping（早停）

训练时持续监控模型在验证集上的性能（loss、accuracy），当验证集性能停止提升甚至开始下降时，提前终止训练。

策略：
- 监控验证集loss/accuracy
- 连续若干epoch不提升则停止
- 取验证集性能最好时的模型参数

注意：
- 有可能不是全局最优解
- 需要通过经验值判断patience（等待轮数）

## Dropout

训练时随机"丢弃"一部分神经元（输出置0），使网络不依赖任何单个神经元：

```python
nn.Dropout(p=0.5)  # 50%概率丢弃
```

原理：
- 每次前向传播随机丢弃不同神经元，相当于训练了多个不同网络的集成
- 减少神经元之间的共适应（co-adaptation）
- 使网络的"有效值"减少，降低对噪声的响应

注意：
- 训练时启用（model.train()），测试时关闭（model.eval()）
- 测试时所有权重都使用，但乘以(1-p)保持期望值一致（PyTorch自动处理）
