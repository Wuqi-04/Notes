# 经典卷积网络

## 发展历程

| 网络 | 年份 | 层数 | Top-5错误率 | 关键创新 |
|------|------|------|-------------|----------|
| LeNet | 1998 | 5 | - | 卷积+池化的奠基 |
| AlexNet | 2012 | 8 | 15.3% | ReLU、Dropout、GPU训练 |
| VGG | 2014 | 16/19 | 7.3% | 小卷积核堆叠 |
| GoogLeNet | 2014 | 22 | 6.7% | Inception模块 |
| ResNet | 2015 | 50/101/152 | 3.6% | 残差连接 |

## LeNet (1998)

LeCun提出，用于手写数字识别：

```
Conv(1→6, 5x5) → Pool → Conv(6→16, 5x5) → Pool → FC(400→120) → FC(120→84) → FC(84→10)
```

- 奠定了CNN的基本结构：卷积+池化+全连接
- 现代CNN的雏形

## AlexNet (2012)

ImageNet 2012冠军，深度学习爆发的起点：

- 首次使用ReLU激活函数（替代Sigmoid/Tanh）
- 使用Dropout防止过拟合
- 双GPU训练
- 数据增强
- 8层网络（5卷积+3全连接）

## VGG (2014)

核心创新：探索出**小卷积核可以提高计算速度且不影响精度**。

- 全部使用3x3卷积核
- 两个3x3卷积堆叠的感受野等于一个5x5，三个等于7x7
- 但参数量更少，且有更多非线性
- 结构简洁规整，常用作特征提取backbone

```python
# VGG风格块
def vgg_block(in_c, out_c, num_convs):
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(in_c, out_c, 3, padding=1))
        layers.append(nn.ReLU())
        in_c = out_c
    layers.append(nn.MaxPool2d(2, 2))
    return nn.Sequential(*layers)
```

## ResNet (2015)

### 解决的问题：退化问题

随着网络层数增加：
- 训练误差反而升高（56层比20层差）——不是过拟合，是深层网络难优化
- 测试误差同步升高

加入残差连接后：
- 训练误差随深度持续下降
- 测试误差同步降低
- 110层效果最好

### 残差块

$$y = F(x, \{W_i\}) + x$$

- shortcut connection将输入直接加到输出
- 网络只需学习残差F(x) = H(x) - x
- 梯度可以通过shortcut直接回传，解决梯度消失/爆炸

### 梯度消失/爆炸的原因

反向传播的链式连乘 + 深层叠加的指数衰减：
- 梯度消失：连乘的小数使浅层梯度趋近0
- 梯度爆炸：连乘的大数使梯度失控

残差连接保证至少有完整的梯度（1.0）通过shortcut传回浅层。

### 不同网络对比

- ResNet-50：25.6M参数，76.1% top-1，性价比最高
- ResNet-101：44.5M参数，77.4%
- ResNet-152：60.2M参数，78.3%

## nn.Module网络结构树

PyTorch中网络结构本质上是一个模块树：

- `nn.Module` 是所有网络模块的基类
- 一个Module可以包含子Module（Sequential、自定义层）
- 形成树状嵌套结构
- `.parameters()` 递归获取所有参数
- `.children()` / `.named_children()` 遍历直接子模块
- `.modules()` 遍历所有模块（包括自身）

```python
for name, module in model.named_modules():
    print(name, module)
```
