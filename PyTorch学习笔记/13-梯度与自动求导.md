# 梯度与自动求导

## 什么是梯度

梯度（gradient）定义为所有偏微分组成的向量：

- **长度（模）**：函数的变化率大小
- **方向**：函数值增长最快的方向

偏微分（partial derivative）是方向固定的标量。

### 梯度下降原理

梯度方向 = 函数值上升最快的方向
负梯度方向 = 函数值下降最快的方向

只要步长（学习率）合适，不断沿负梯度方向走一小步，最终梯度接近0，即得到极小值。

### 影响因素

- 初始化值：不同初始点可能收敛到不同极小值
- 学习率（步长）：太大会震荡，太小收敛慢

### 鞍点（Saddle Point）

梯度为0，但既不是极大值也不是极小值的临界点。鞍点会影响优化器的选择，可能导致训练停滞。

### 局部极小值

模型可能陷入局部极小值而非全局最小值。解决方法：
- 添加动量（Momentum），利用惯性冲出局部极小值
- 合适的初始化

## ReLU函数

$$\text{ReLU}(x) = \max(0, x)$$

- 目前神经网络中使用最多的激活函数
- 梯度好计算：x>0时梯度为1，x<=0时梯度为0
- 不会对梯度进行放大缩小，减少梯度爆炸和梯度弥散
- 计算简单高效

## 自动求导

### MSE均方误差求导

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
w = torch.tensor(3.0, requires_grad=True)

y = w * x
loss = (y - 5) ** 2  # MSE

# 方式1：torch.autograd.grad
grad = torch.autograd.grad(loss, [w])  # 返回元组

# 方式2：backward
loss.backward()
print(w.grad)  # 自动反向传播
```

注意：
- 需要对哪些变量求导，必须设置 `requires_grad=True`
- PyTorch是动态图，每次前向传播都重新构建计算图
- 两种求导方式返回值形式不同：autograd.grad返回梯度元组，backward将梯度累加到.grad属性

### Softmax函数

$$\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$$

- 输出区间(0,1)，所有值之和为1
- 具有转义成概率的能力
- 可以放大差距（指数效应）
- 适用于多分类问题

### 梯度累积

```python
# 默认梯度会累加，每次反向传播前需要清零
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

使用 `retain_graph=True` 可以保留计算图进行多次反向传播，但第二次求导仍是一阶梯度。
