# 交叉熵与多分类实战

## 熵（Entropy）

熵是对随机变量不确定性的严格量化度量，也可以理解为一个随机事件所包含的平均信息量。

$$H(X) = -\sum_{i} p(x_i) \log p(x_i)$$

- 熵描述一个随机变量所有可能结果的平均不确定性
- 本质是自信息按概率加权的平均值
- **熵越大**：分布越均匀，结果越难预测，不确定性越高
- **熵越小**：分布越集中，结果越确定，混乱度越低

### 自信息

$$I(x_i) = -\log p(x_i)$$

- 单次事件发生的意外程度
- 事件发生概率越小，自信息越大（越意外）
- 事件发生概率越大，自信息越小（越平常）

## 交叉熵（Cross Entropy）

$$H(p, q) = -\sum_i p(x_i) \log q(x_i)$$

- p：真实分布（标签）
- q：预测分布（模型输出）
- 交叉熵衡量两个分布的差异
- 交叉熵越小，预测分布越接近真实分布

在分类任务中，交叉熵损失等价于负对数似然：

$$L = -\log q(y_{true})$$

PyTorch中 `nn.CrossEntropyLoss` 内置了Softmax，使用时网络最后一层不需要加Softmax。

## 多分类问题实战

### 网络结构

以MNIST手写数字分类为例：

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# 数据加载
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)

# 模型
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)

# 损失和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# 训练
for epoch in range(10):
    for batch_idx, (data, target) in enumerate(train_loader):
        data = data.view(data.size(0), -1)  # 展平
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
```

### 从模型输出到预测准确率

1. 模型输出 logits（未归一化的分数）
2. `argmax(dim=1)` 取最大分数的索引作为预测类别
3. 与真实标签比较，计算准确率

```python
# 预测
output = model(data)
pred = output.argmax(dim=1)
correct = (pred == target).sum().item()
accuracy = correct / target.size(0)
```

## Visdom可视化

Visdom是PyTorch的可视化工具，可实时监控训练过程。

启动方式：
```bash
python -m visdom.server
```

启动后在浏览器打开生成的地址，即可实时查看：
- 单条曲线（loss曲线）
- 多条曲线（loss和accuracy）
- 注意：同一个图上必须是同一种数据类型

## 训练曲线解读

一组典型的训练问题曲线：

1. **过拟合**：训练集表现持续优化，但测试集表现跟不上，差距随训练扩大。模型"死记硬背"训练集，泛化能力下降
2. **训练后期震荡**：测试集loss出现尖峰、准确率暴跌，说明学习率过大，模型在最优解附近跳动，无法稳定收敛
