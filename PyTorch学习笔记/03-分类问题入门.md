# 分类问题入门

以手写数字识别（MNIST）为例。

## 数据处理

### 划分数据集

将数据集划分为训练集（train）和测试集（test）：
- 训练集：用于模型训练
- 测试集：用于评估模型泛化能力

### 数据展平（Flat）

将二维图像数据转换为一维数据：
- 忽略二维的位置相关性，x = [1, n]，其中1表示维度
- 28x28的图像展平为784维向量

## 网络结构

手写数字无法用一个简单线性模型表示，需要用多个线性函数嵌套：

```
输入(784) → H1 → H2 → H3 → 输出(10)
```

使用矩阵相乘处理三个线性层的嵌套。

### 为什么需要非线性激活函数？

尽管用了三个线性层嵌套，但线性层的嵌套仍然是线性的，无法拟合非线性问题。

在每个线性部分后添加 Non-linear Factor（非线性部分），即激活函数：
- Sigmoid
- ReLU（最常用）

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)
```

## Loss计算与One-hot编码

### 标签编码方式

1. 直接用数值0~9表示：H3输出 [1,1]
2. **One-hot编码**（适用于分类）：把标签展开为全0、对应类别为1的n维向量

### 为什么用One-hot编码？

- 类别是完全平等的，若直接使用数值大小编码，模型会解读为类别相似度，强行给毫无关系的类别加上"远近关系"
- One-hot编码中标签是等长稀疏矩阵，任意两个标签之间的欧式距离都相等
- 因此所有类别在向量空间是完全平等、相互独立的
