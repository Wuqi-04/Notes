# 拼接与拆分

## 拼接（Merge）

### cat（沿已有维度拼接）

```python
a = torch.rand(4, 3, 28, 28)
b = torch.rand(4, 3, 28, 28)

torch.cat([a, b], dim=0)  # [8, 3, 28, 28]
torch.cat([a, b], dim=2)  # [4, 3, 56, 28]
```

- 在指定维度上拼接，其他维度大小必须一致
- 不增加新维度，只在已有维度上扩展
- dim参数的语义由开发者理解（如dim=0拼接batch）

### stack（创建新维度拼接）

```python
a = torch.rand(4, 3, 28, 28)
b = torch.rand(4, 3, 28, 28)

torch.stack([a, b], dim=0)  # [2, 4, 3, 28, 28]
torch.stack([a, b], dim=2)  # [4, 3, 2, 28, 28]
```

- 在指定位置插入新维度，维度大小为tensor个数
- 所有输入tensor的形状必须完全一致
- 新维度的语义由开发者定义

## 拆分（Split）

### split（按长度拆分）

```python
c = torch.rand(8, 3, 28, 28)

# 按指定长度拆分
a, b = c.split([4, 4], dim=0)  # a:[4,3,28,28], b:[4,3,28,28]
a, b, c2 = c.split([3, 3, 2], dim=0)  # 拆成3份

# 按固定长度拆分
a, b = c.split(4, dim=0)  # 每份长度4
```

- 需要明确拆分后的tensor个数，否则返回tuple
- 可以用列表接收或用 `*` 解包

### chunk（按数量拆分）

```python
c = torch.rand(8, 3, 28, 28)

a, b = c.chunk(2, dim=0)  # 拆成2个，每个[4,3,28,28]
```

- 指定最终拆成几份
- 按维度均分
