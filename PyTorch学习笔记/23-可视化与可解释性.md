# 可视化与可解释性

## 训练过程可视化

### Visdom

PyTorch生态的实时可视化工具：

```bash
# 启动
python -m visdom.server
```

启动后在浏览器打开 http://localhost:8097 即可实时监控。

基本用法：

```python
from visdom import Visdom

viz = Visdom()

# 画单条曲线
viz.line(X=[epoch], Y=[loss], win='loss', update='append')

# 画多条曲线
viz.line(X=[[epoch, epoch]], Y=[[train_loss, val_loss]],
         win='loss', update='append',
         legend=['train', 'val'])
```

注意：同一个图上必须是同一种数据类型。

### Matplotlib

更通用的绘图方式，训练后画曲线图：

```python
import matplotlib.pyplot as plt
matplotlib.use('Agg')  # 非交互后端，直接存文件

plt.plot(train_losses, label='Train Loss')
plt.plot(val_losses, label='Val Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.savefig('loss_curve.png')
```

## 训练曲线解读

### 过拟合曲线
- 训练loss持续下降，验证loss先降后升
- 训练accuracy持续上升，验证accuracy停滞或下降
- 差距随训练扩大

### 学习率过大
- 训练后期loss出现尖峰
- accuracy同步暴跌
- 模型在最优解附近震荡，无法稳定收敛

### 正常收敛
- 训练和验证loss同步下降后趋于平稳
- accuracy同步上升后平稳
- 差距较小且稳定

## Grad-CAM

Grad-CAM（Gradient-weighted Class Activation Mapping）是最常用的模型可解释性方法。

### 原理

1. 前向传播得到目标类别的分数
2. 反向传播计算该类别对最后一层卷积特征图的梯度
3. 对梯度做全局平均池化，得到每个通道的权重
4. 权重与特征图加权求和，经ReLU得到热力图
5. 热力图上采样到输入图像尺寸，叠加显示

### 意义

回答"模型为什么把这张图分类为这个类别"——高亮区域就是模型决策时关注的位置。

在细粒度分类中，Grad-CAM可以验证模型是否关注了正确的判别区域（如犬种的耳朵、口鼻），还是在依赖背景等无关信息。

### 使用

```python
from pytorch_grad_cam import GradCAM
from pytorch_grad_cam.utils.image import show_cam_on_image

target_layers = [model.backbone.layer4[-1]]
cam = GradCAM(model=model, target_layers=target_layers)
grayscale_cam = cam(input_tensor=input_tensor)
visualization = show_cam_on_image(rgb_img, grayscale_cam[0, :])
```

## 其他可视化
