# 数据增强

数据增强通过对训练图像进行随机变换，人工扩充数据集，提高模型泛化能力。

## 常用增强方法

### 几何变换

- **随机裁剪（Random Crop）**：从图像中随机裁剪区域
- **随机水平翻转（Random Horizontal Flip）**：左右翻转（犬种识别中适用）
- **随机旋转（Random Rotation）**：小角度旋转（如15度）
- **缩放（Scale/Jitter）**：随机缩放

### 颜色变换

- **ColorJitter**：随机调整亮度、对比度、饱和度、色调
- **随机灰度（Random Grayscale）**：以一定概率转为灰度
- **Normalize**：用ImageNet均值方差归一化

### 其他

- **Random Erasing**：随机遮挡图像区域，模拟遮挡情况
- **Mixup**：两张图像按比例混合
- **CutMix**：裁剪区域粘贴另一张图

## PyTorch实现

```python
from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.6, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.1),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    ),
    transforms.RandomErasing(p=0.3),
])

# 验证/测试时不做随机增强
val_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    ),
])
```

## 注意事项

- 数据增强只在训练时使用，验证/测试时用确定性变换
- 增强要合理：垂直翻转对狗品种识别不适用（狗不会倒着出现）
- 归一化的均值方差要与预训练模型一致（ImageNet）
- 数据增强和输入分辨率的提升往往比改网络结构收益更大
