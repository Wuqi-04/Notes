# 索引与切片

## 连续索引

类似Python列表和多级页表的索引方式：

```python
a = torch.rand(4, 3, 28, 28)  # [B, C, H, W]

a[0]          # 第0张图片，shape: [3, 28, 28]
a[0, 0]       # 第0张图片的第0个通道，shape: [28, 28]
a[0, 0, 2, 3] # 标量
```

### 切片语法

```python
a[:2]          # 前2张图片
a[:2, 1:, :, :]    # 前2张图片，从第1通道到最后
a[:2, -1:, :, :]   # 前2张图片，最后一个通道
a[:, :, 0:28:2, :] # 高从0到28，步长2（隔行采样）
```

规则：
- `:x` 从0开始取x个
- `x:` 从x取到末尾
- `:` 取全部
- `-x:` 从倒数第x个取到末尾
- 正向索引从0开始，负向索引从-1开始

### 省略号索引

```python
a[1, ...]      # 等价于 a[1, :, :, :]，shape: [3, 28, 28]
a[..., :2]     # 等价于 a[:, :, :, :2]
```

`...` 表示之后的所有维度都取，在最后面时可省略。

## 间隔索引

```python
a[:, :, 0:28:2, ::2]
# [start:end:step]
# 高从0到28步长2，宽全部步长2
```

## index_select（指定维度索引）

```python
a.index_select(1, torch.tensor([1, 2]))
# 在第1维（通道维）选取第1、2个通道
# shape: [4, 2, 28, 28]

a.index_select(0, torch.arange(3))
# 在第0维选取前3张
```

注意：`index_select` 的索引必须是tensor，不能是Python list。

## mask索引

```python
x = torch.randn(3, 4)
mask = x.ge(0.5)              # >= 0.5的位置为1，其余为0
y = torch.masked_select(x, mask)  # 提取符合条件的元素
```

- `ge` = greater equal，`gt` = greater than，`le` = less equal，`lt` = less than
- 提取后的tensor为一维不定长tensor，与原shape无关

## take索引

```python
src = torch.tensor([[1, 2], [3, 4]])
torch.take(src, torch.tensor([0, 2, 3]))  # tensor([1, 3, 4])
```

将tensor打平成一维后，按全局索引取元素。

注意：masked_select和take都会将tensor打平（flat），使用较少。
