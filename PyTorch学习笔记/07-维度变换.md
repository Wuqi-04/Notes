# 维度变换

## view / reshape

功能完全相同，改变tensor的形状（只要元素总数不变）：

```python
a = torch.rand(4, 1, 28, 28)

a.view(4, 28*28)      # [4, 784]，展平为全连接层输入
a.view(4*28, 28)      # [112, 28]
a.view(4, 28, 28)     # [4, 28, 28]，去掉通道维
```

物理意义举例：
- `[4, 784]`：将channel、height、width合并，4张图片各用784维向量表示，适用于全连接层
- `[4, 28, 28]`：合并batch和channel，得到单通道图片格式 [N, H, W]

注意：
- view/reshape 会丢失维度顺序信息，需要人为跟踪
- 一旦view后原数据维度信息丢失，无法自动复原
- 必须保证 `prod(size)` 不变

## unsqueeze（增加维度）

```python
a = torch.rand(4, 28, 28)

a.unsqueeze(0)   # 在第0维前插入维度 → [1, 4, 28, 28]
a.unsqueeze(-1)  # 在最后一维后插入 → [4, 28, 28, 1]
a.unsqueeze(2)   # 在第2维前插入 → [4, 28, 1, 28]
```

- 正数：在第a维**前**插入
- 负数：在倒数第a维**后**插入
- 不改变数据本身，只是改变形状理解方式
- 可连续调用：`x.unsqueeze(0).unsqueeze(-1)`

## squeeze（删减维度）

```python
a = torch.rand(1, 4, 1, 28)

a.squeeze()    # 删除所有大小为1的维度 → [4, 28]
a.squeeze(0)   # 删除第0维（大小为1）→ [4, 1, 28]
a.squeeze(2)   # 删除第2维（大小为1）→ [1, 4, 28]
```

只能删除大小为1的维度，若该维大小不为1则不变。

## expand / repeat（维度扩展）

```python
a = torch.rand(1, 3, 1, 1)

# expand：推荐，不复制数据（虚拟维度）
a.expand(4, 3, 28, 28)   # [4, 3, 28, 28]
a.expand(-1, 3, -1, -1)  # -1表示该维不变

# repeat：复制数据（占用内存）
a.repeat(4, 1, 28, 28)   # 参数是各维度复制次数
```

- expand：只改变理解方式，必要时才复制数据，推荐使用
- repeat：一定会复制数据，参数是复制次数

## 维度交换

### t（转置）

```python
a = torch.rand(3, 4)
a.t()    # [4, 3]，只适用于二维
```

### transpose（两两交换）

```python
a = torch.rand(4, 3, 28, 28)
a.transpose(1, 3)        # [4, 28, 28, 3]，交换通道和宽
a.transpose(1, 3).contiguous()  # 交换后内存不连续，需contiguous
```

- transpose只交换逻辑顺序，不改变内存顺序，导致存储不连续
- 使用view前必须先contiguous
- 通常写法：`a.transpose(1,3).contiguous().view(...)`

### permute（任意重排）

```python
a = torch.rand(4, 3, 28, 28)
a.permute(0, 2, 3, 1)   # [B, H, W, C] = [4, 28, 28, 3]
```

- 可同时重排多个维度
- 自动处理内存连续性
- `[B, H, W, C]` 是numpy的图片存储格式

### 展平与还原的理解

- 展平：由内到外（最后一维先展）
- 还原：从外到内（第一维先恢复）
- 维度交换后要特别注意数据的物理顺序是否一致
