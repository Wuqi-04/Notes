# Broadcast（广播机制）

## 概念

Broadcast是PyTorch的自动扩展机制，在不复制数据的情况下，让不同形状的tensor进行运算。

核心思想：利用虚拟维度，实际上原来的tensor大小不变。

## 规则

1. **从小维度开始对齐**，大维度开始匹配，若不匹配则插入新的大维度
2. 插入的新维度扩展至与对应维度大小相等
3. 维度大小为1的维度可以广播到任意大小
4. 大维度（左侧），小维度（右侧）

```python
# 示例1：标量广播
a = torch.rand(3, 4)
b = 1.0
(a + b).shape  # [3, 4]，b自动广播

# 示例2：维度为1的广播
a = torch.rand(4, 3, 28, 28)
b = torch.rand(1, 3, 1, 1)
(a + b).shape  # [4, 3, 28, 28]，b自动扩展

# 示例3：自动插入维度
a = torch.rand(4, 3, 28, 28)
b = torch.rand(28)  # [28] → [1, 1, 1, 28] → [4, 3, 28, 28]
(a + b).shape  # [4, 3, 28, 28]
```

## 注意事项

- 小维度部分必须手动对齐（或自动补1）
- 维度必须不同才能使用广播（相同大小不会广播）
- 广播节省大量内存，不需要实际复制数据

## 实际应用

当tensor需要与一个标量或小维度tensor运算时，如果只用unsqueeze和expand需要很多操作，广播机制自动完成这些步骤。

例如：给每个通道加上不同的偏置：

```python
feature = torch.rand(4, 3, 28, 28)  # [B, C, H, W]
bias = torch.rand(3)                # [C]
# bias自动广播为 [1, 3, 1, 1] → [4, 3, 28, 28]
result = feature + bias
```
