# 高阶操作

## where（条件选择）

```python
torch.where(condition, x, y)
```

- condition为True的位置取x，False的位置取y
- 等价于：`condition ? x : y`

```python
a = torch.tensor([1.0, 2.0, 3.0])
b = torch.tensor([4.0, 5.0, 6.0])
cond = torch.tensor([True, False, True])

torch.where(cond, a, b)  # [1, 5, 3]
```

可作为复杂的时序控制：根据条件在两个tensor间选择。

```python
# 示例：概率大于0.5取a，否则取b
cond = prob > 0.5
result = torch.where(cond, a, b)
```

## gather（按索引收集）

```python
torch.gather(input, dim, index)
```

沿指定维度dim，用index张量去input中收集元素，输出形状与index完全一致。

```python
# 示例：多分类中根据标签索引取对应类别的概率
prob = torch.rand(4, 10)        # 4个样本，10个类别的概率
label = torch.tensor([3, 5, 2, 7])  # 每个样本的真实标签
label = label.unsqueeze(1)      # [4, 1]

# 取每个样本真实类别的概率
selected = torch.gather(prob, 1, label)  # [4, 1]
```

gather常用于：
1. 根据标签索引取对应类别的预测概率
2. 相对索引转绝对索引
3. 根据索引表从input中查询元素

### gather的工作原理

对于输出的每个位置 `out[i][j]`：
- 如果dim=1：`out[i][j] = input[i][index[i][j]]`
- 如果dim=0：`out[i][j] = input[index[i][j]][j]`

index的形状决定输出形状，input和index在非dim维度上需要可广播。
