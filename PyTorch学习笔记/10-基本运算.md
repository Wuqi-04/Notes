# 基本运算

## 四则运算

```python
a = torch.rand(3, 4)
b = torch.rand(3, 4)

a + b       # 加法（对应位置）
a - b       # 减法
a * b       # 乘法（对应位置，逐元素乘）
a / b       # 除法
```

- 完全遵循Broadcast机制
- 建议直接使用运算符，更清晰明确

## 矩阵乘法

```python
a = torch.rand(2, 3)
b = torch.rand(3, 4)

# 三种方式等价
torch.mm(a, b)       # 只适用于二维矩阵
torch.matmul(a, b)   # 通用
a @ b                # 运算符，推荐
```

注意：
- PyTorch中线性层权重规范写法为 `w = torch.rand(ch_out, ch_in)`
- 因此使用时需要 `x @ w.t()` 先转置
- `matmul` 对高维tensor：取最后两个维度做矩阵乘法，前面的维度视为batch并行计算

```python
# 高维矩阵乘法
a = torch.rand(4, 3, 28, 64)   # [B, ..., 28, 64]
b = torch.rand(4, 3, 64, 32)   # [B, ..., 64, 32]
c = a @ b                       # [4, 3, 28, 32]，4*3个矩阵并行相乘
```

## 幂运算

```python
a = torch.full([2, 2], 2)

a ** 2       # 平方
a.pow(2)     # 同上
a ** 0.5     # 开方
a.sqrt()     # 同上
```

## 指数与对数

```python
torch.exp(a)   # e^a
torch.log(a)   # ln(a)，自然对数
torch.log2(a)  # log2
torch.log10(a) # log10
```

## 近似值

```python
a = torch.tensor([3.14, 2.5, -1.7])

a.floor()   # 向下取整：[3, 2, -2]
a.ceil()    # 向上取整：[4, 3, -1]
a.round()   # 四舍五入：[3, 2, -2]
a.trunc()   # 保留整数部分：[3, 2, -1]
a.frac()    # 保留小数部分：[0.14, 0.5, -0.7]
```

## clamp（裁剪）

```python
a = torch.tensor([-1.0, 0.5, 2.0, 5.0])

a.clamp(0)        # 小于0的裁剪为0：[0, 0.5, 2, 5]
a.clamp(0, 3)     # 小于0→0，大于3→3：[0, 0.5, 2, 3]
```

常用于梯度裁剪（gradient clipping），防止梯度爆炸。
