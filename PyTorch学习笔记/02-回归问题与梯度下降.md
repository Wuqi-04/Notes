# 回归问题与梯度下降

## 梯度下降算法

梯度下降算法是深度学习的核心内容。每次求导之后，用当前x的值减去学习率乘上当前的导数值，不断重复这个过程。深度学习最终会在理论值周围小幅度地波动，这时候就得到了一个合适的解，这个式子就是梯度下降的核心规则。

梯度下降可以利用不同的求解器进行优化，核心规则保持不变，在此基础上施加不同的约束，使得求解的速度或者精度得到提高。

## 闭式解

Closed Form Solution即闭式解，是可以精确求解的方程。不过实际问题中很少存在精确解，需要根据实际情况求出近似解，而且实际数据中经常含有噪声，通常会用多个方程来求解，这样可以减小噪声带来的影响。以加入高斯噪声的情况为例，由于梯度算法是求最值的，因此通过差值的平方来求得最小误差，本质上就是构造优化目标然后求解这个优化目标。

当loss函数能够进行可视化的时候，可以很方便直观地求出最优解，但实际情况中x的维度很高，很难进行三维可视化。

## Linear Regression与Logistic Regression

Linear Regression的求解范围属于整个实数空间，是连续的。Logistic Regression在Linear Regression的基础上增加了压缩函数，把实数空间压缩到0到1的范围。Classification则是分类问题。

Logistic Regression用于二分类概率问题，比如输出0.85，表示这封邮件是垃圾邮件的概率为85%。Classification的结果则是1（垃圾邮件）或者0（正常邮件），两者需要区分开。
