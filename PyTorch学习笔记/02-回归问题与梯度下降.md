# 回归问题与梯度下降

## 梯度下降算法

梯度下降是深度学习的核心优化算法。

核心规则：

$$x_{new} = x - \eta \cdot \frac{df}{dx}$$

每次求导后，用当前 x 的值减去学习率（步长）乘上当前的导数值。

- 深度学习最终会在理论值附近小幅度波动，即得到一个合适解
- 可利用不同求解器（优化器）进行优化，核心规则不变，进行不同的约束使求解速度/精度提高
- 常见优化器：SGD、Momentum、Adam、AdamW等

## Closed Form Solution（闭式解）

- 可精确求解的方程称为闭式解
- 实际问题很少有精确解，通常求近似解
- 实际数据常含有噪声，通常用多个方程求解以减小噪声影响
- 加入高斯噪声后，通过差值的平方求最小误差（最小二乘法）
- 本质就是构造优化目标，求解优化目标

当 loss 函数能可视化时，可以很直观地求出最优解；但实际情况中 x 的维度很高，很难进行三维可视化。

## Linear Regression（线性回归）

三种问题的区分：

1. **Linear Regression**：求解范围属于整个实数空间（连续值）
2. **Logistic Regression**：在 Linear Regression 基础上增加压缩函数（Sigmoid），将实数空间压缩到 [0,1]，表示概率
3. **Classification**：分类问题，输出离散类别

### Logistic Regression vs Classification

- Logistic Regression 输出：0.85 → 这封邮件是垃圾邮件的概率是 85%
- Classification 结果：1（垃圾邮件）或 0（正常邮件）

Logistic Regression 本质上是二分类概率问题，输出的是概率值；Classification 输出的是确定的类别。
