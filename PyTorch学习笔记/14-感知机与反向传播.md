# 感知机与反向传播

## 前向传播

前向传播：求导之前先向右计算一次所有变量值（输入数据"喂"给模型，按顺序计算出最终输出的过程）。

### 单层单输出感知机

最简单的感知机模型：

$$y = \sigma(w^T x + b)$$

其中：
- x：输入向量
- w：权重向量
- b：偏置
- sigma：激活函数（如Sigmoid）

### 多输出感知机

输出层有多个神经元，每个神经元对应一个类别：

$$y_k = \sigma\left(\sum_j w_{kj} x_j + b_k\right)$$

## 链式法则

链式法则是反向传播的数学基础，本质就是复合函数求导：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial w}$$

添加多个隐藏层实际上就是嵌套多个复合函数，让模型能拟合更复杂的模式（将上一个隐藏层的输出作为下一个隐藏层的输入）。

反向传播从输出层开始，逐层向输入层计算梯度：

```
输出层梯度 → 隐藏层2梯度 → 隐藏层1梯度 → 输入层梯度
```

## 2层感知机（MLP）

```python
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

每一层分为三段式：
1. 线性变换（Linear）
2. 激活函数（ReLU）
3. 传递给下一层

## 参数量计算

- 一层的参数量 = 输入维度 x 输出维度 + 输出维度（偏置）
- 总参数量 = 所有层的参数之和
- 每个隐藏层的神经元数量是人工设定的超参数
- 输出层维度对应分类任务的类别数

## 初始化与学习率的重要性

- 修改初始化值会影响局部极小值的搜索结果，可能找到不同的极小值
- 学习率过大：在最优解附近震荡，无法收敛
- 学习率过小：收敛缓慢，可能陷入鞍点
- 初始化和学习率的选取十分重要
