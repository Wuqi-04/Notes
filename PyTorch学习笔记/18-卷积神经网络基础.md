# 卷积神经网络基础

## 什么是卷积

### 与信息光学的对比

学习过信息光学后，可以将信息光学中的卷积与卷积神经网络的"仿生学"进行对比：

- **卷积**：用于新特征提取。有权重（卷积核），根据核的大小，对原像素对应部分与权重相乘求和，得到新的特征
- **池化**：用于空间压缩、特征筛选。池化层没有权重，只根据一定规则滑动筛选（如取区域最大值、平均值）

每一组「卷积 + 池化」就是一次"特征提炼 + 空间压缩"。

### 卷积层参数

- 卷积核大小（kernel size）：如3x3、5x5
- 步长（stride）：每次滑动的距离
- 填充（padding）：边缘补零
- 输入通道数（in_channels）
- 输出通道数（out_channels）：即卷积核数量

```python
nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, stride=1, padding=1)
```

## 多通道卷积

### 同一层的多通道运算

- 输入有C个通道，每个卷积核也有C个通道
- 同一卷积核在不同通道上的权重不同
- 原因：不同通道携带的信息不同（RGB分别记录红、绿、蓝亮度），对提取某类特征的贡献不同
- 不同卷积核分别运算，得到不同的输出特征图

### 参数量计算

一个卷积核的参数量 = in_channels x kernel_h x kernel_w + 1（偏置）
总参数量 = out_channels x (in_channels x kernel_h x kernel_w + 1)

## 特征提取层次

卷积神经网络从低维特征到高维特征逐层分析：

1. **浅层**：边缘、纹理、颜色等低级特征
2. **中层**：简单形状、局部模式
3. **深层**：语义概念、物体部件
4. **最后**：全连接层分类

## 卷积核可视化

- **浅层卷积核**：可以直接把权重数值当图像渲染出来，通常是边缘、颜色检测器
- **深层卷积核**：常用「激活最大化」方法——反向优化输入图像，让该卷积核输出响应最大，生成的图像就是它最"擅长检测"的特征

## 特征图可视化

输入一张图片，观察它对图片哪些区域有响应（激活值大的位置）。

## "黑箱"问题

### 什么是黑箱

深度学习模型是天然的"黑箱"：
1. 可以精准控制输入、观测输出，通过反向传播让效果变好
2. 但无法完整、直观、因果性地解释：模型为什么做这个决策？每个参数对应什么语义？从输入到输出的完整逻辑链是什么？

原因：
- 超大规模的分布式参数空间
- 深层非线性的层层叠加
- 特征是自动涌现的，不是人工预设的

模型学到的特征可能和人类认知对齐（如浅层学到边缘），也可能学到人类无法理解的统计模式。

### 可解释性研究

不是要把深度学习变成白箱，而是从不同维度增加可理解性：

1. **全局可解释性**：理解模型整体的决策逻辑
2. **局部可解释性**：解释单个样本的决策原因——"这张图为什么判断成猫？主要看了哪个区域？"

**Grad-CAM**是最常用的局部可解释性方法：
- 原理：通过反向传播梯度，计算输入图像上每个像素对最终分类结果的贡献
- 输出：热力图，高亮区域就是模型决策时重点关注的位置
