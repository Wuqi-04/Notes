# 统计属性

## 范数（norm）

```python
a = torch.rand(2, 3)

a.norm(1)       # L1范数：所有元素绝对值之和
a.norm(2)       # L2范数：所有元素平方和开根号
a.norm(1, dim=0)  # 沿dim=0求L1范数
```

- 向量范数（vector norm）和矩阵范数（matrix norm）
- 注意与 `normalize`（正则化）区分

## 基本统计

```python
a = torch.rand(4, 10)

a.mean()       # 均值
a.sum()        # 求和
a.min()        # 最小值
a.max()        # 最大值
a.prod()       # 累乘
a.argmax()     # 最大值的全局索引（先打平）
a.argmin()     # 最小值的全局索引
```

### 沿指定维度

```python
a = torch.rand(4, 10)

a.max(dim=1)
# 返回 (values, indices)
# values: 每行最大值 [4]
# indices: 每行最大值索引 [4]

a.argmax(dim=1)   # 不打平，沿dim=1取最大值索引
```

### keepdim

```python
a.max(dim=1, keepdim=True)
# 保持原维度数，输出shape为[4, 1]而非[4]
```

每次统计操作后默认会降维（squeeze），keepdim保持形状。

## top-k 与 k-th

```python
a = torch.rand(4, 10)

# top-k
a.topk(3, dim=1)              # 每行前3大的值和索引
a.topk(3, dim=1, largest=False)  # 前3小

# k-th value
a.kthvalue(3, dim=1)  # 每行第3小的值和索引
```

## 比较操作

```python
a = torch.rand(4, 10)
b = torch.rand(4, 10)

torch.eq(a, b)    # 逐元素比较，返回0/1 tensor
torch.equal(a, b) # 整体比较，返回True/False

a > 0.5           # 逐元素大于，返回bool tensor
a.ge(0.5)         # >=
a.le(0.5)         # <=
```
