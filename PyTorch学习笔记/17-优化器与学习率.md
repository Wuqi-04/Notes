# 优化器与学习率

## 动量（Momentum）

标准SGD在梯度方向变化大的地方会震荡，收敛慢。动量方法引入"惯性"：

$$v_t = \beta v_{t-1} + (1-\beta) g_t$$
$$w_{t+1} = w_t - \eta v_t$$

- 累积历史梯度方向，在一致方向上加速
- 在方向变化处抑制震荡
- 有助于跳出局部极小值和鞍点
- beta通常取0.9

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

## 学习率衰减

学习率过大：训练后期在最优解附近震荡，无法收敛
学习率过小：收敛缓慢

### 方式一：监控衰减（ReduceLROnPlateau）

在一定epoch内，监控指标（如验证loss）不再改善时降低学习率：

```python
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, mode='min', factor=0.1, patience=5
)
# 训练时
scheduler.step(val_loss)
```

### 方式二：阶梯衰减（StepLR）

在一定epoch后固定衰减：

```python
scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer, step_size=10, gamma=0.1
)
```

### 方式三：余弦退火（CosineAnnealingLR）

学习率按余弦曲线从初始值衰减到最小值：

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=num_epochs
)
```

## 常见优化器

| 优化器 | 特点 |
|--------|------|
| SGD | 最基础，加Momentum后效果好 |
| RMSprop | 自适应学习率，适合RNN |
| Adam | Momentum + RMSprop，最常用 |
| AdamW | Adam + 修正权重衰减，Transformer标配 |

```python
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=1e-4)
```
